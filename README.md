# 💳 Штрих-коды и Дисконтные карты (Web Barcode Wallet)

Легкое, быстрое и полностью адаптивное веб-приложение для хранения, сканирования и отображения дисконтных карт и штрих-кодов прямо в браузере. Больше не нужно носить с собой пачку пластиковых карт или загромождать телефон тяжелыми мобильными приложениями.

🔗 **[Попробовать демо / Открыть приложение](https://www.google.com/search?q=%23)** *(если развернуто на GitHub Pages, можно добавить ссылку)*

---

## ✨ Основные возможности

* 📷 **Сканирование с фото:** Распознавание штрих-кодов и QR-кодов с изображений (поддержка `QuaggaJS` и `jsQR`).
* ⌨️ **Ручной ввод:** Быстрое добавление карт по номеру или тексту (поддерживается автоопределение типа кода и популярной сети магазинов).
* 🏷️ **Автоопределение сетей:** Приложение автоматически распознает популярные магазины (Пятёрочка, Магнит, Лента, Fix Price, Перекрёсток, Ашан, Спортмастер и др.) и подбирает фирменный цвет и логотип/бейджик.
* 📱 **Полноэкранный режим:** Клик по любому коду разворачивает его на весь экран с максимальной яркостью для уверенного считывания сканерами на кассах самообслуживания и у кассиров.
* 🎨 **Кастомизация и Темы:**
* Переключение светлой, темной, голубой и зеленой тем оформления.
* Настройка индивидуального цвета для каждой карточки (палитра или свой HEX-код).


* 🔄 **Сортировка перетаскиванием (Drag-and-Drop):** Удобная организация порядка карт под ваши привычки (поддерживается на ПК и мобильных устройствах).
* 💾 **Автосохранение:** Все карты и настройки сохраняются локально в памяти вашего браузера (`localStorage`), не требуют регистрации и облачных серверов.
* 📱 **Mobile-First:** Интерфейс полностью адаптирован под смартфоны (оптимизированные размеры кнопок, отсутствие случайных выделений текста, PWA-friendly верстка).

## 🛠️ Используемые технологии

Проект написан на чистом **HTML5, CSS3 и JavaScript (Vanilla JS)** без использования тяжелых фреймворков (React/Vue), что обеспечивает мгновенную загрузку и работу.

Используемые сторонние библиотеки (подключаются через CDN):

* [JsBarcode](https://github.com/lindell/JsBarcode) — генерация линейных штрих-кодов (EAN-13, EAN-8, Code128, UPC и др.).
* [QRCode.js](https://github.com/soldair/node-qrcode) — генерация QR-кодов.
* [QuaggaJS](https://serratus.github.io/quaggaJS/) & [jsQR](https://github.com/cozmo/jsQR) — сканирование и распознавание кодов по загруженным изображениям.

## 🚀 Быстрый старт (Запуск локально)

Этот проект является полностью клиентским (Single-Page Application), поэтому для его запуска не нужен сервер Node.js или бэкенд.

1. Клонируйте репозиторий или скачайте архив:
```bash
git clone https://github.com/ваш-логин/ваш-репозиторий.git

```


2. Откройте файл **`index.html`** в любом современном браузере.

### Размещение на GitHub Pages:

1. Загрузите файл `index.html` в корневой каталог вашего репозитория на GitHub.
2. Перейдите в настройки репозитория: **Settings** ➡️ **Pages**.
3. В разделе **Build and deployment** выберите ветку (`main` / `root`) и нажмите **Save**.
4. Через минуту приложение будет доступно по публичной ссылке!

## 💡 Как пользоваться

1. **Добавить карту:**
* Нажмите кнопку **«📷 Сканировать с фото»** и выберите скриншот или фото карты.
* Либо введите цифры штрих-кода вручную в поле ввода и нажмите **«➕ Добавить»**.


2. **Показать на кассе:** Нажмите на изображение штрих-кода/QR-кода на карточке, чтобы открыть его на весь экран.
3. **Редактировать:**
* Кликните по названию карты, чтобы изменить его текст.
* Нажмите на иконку шестеренки на карточке, чтобы изменить её цвет.
* Нажмите на плашку с названием магазина, чтобы вручную перепривязать бренд.


4. **Удалить:** Нажмите на крестик в левой панели карточки.
