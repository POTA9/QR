# 💳 Штрих-коды и Дисконтные карты

Лёгкое, быстрое и полностью адаптивное веб-приложение для хранения, сканирования и отображения дисконтных карт и штрих-кодов прямо в браузере.

## ✨ Основные возможности

- 📷 **Сканирование с фото:** Распознавание штрих-кодов и QR-кодов с изображений (поддержка `QuaggaJS` и `jsQR`).
- ⌨️ **Ручной ввод:** Быстрое добавление карт по номеру или тексту.
- 🏷️ **Автоопределение сетей:** Автоматическое распознавание популярных магазинов (Пятёрочка, Магнит, Лента, Fix Price, Перекрёсток, Ашан, Спортмастер и др.) с подбором цвета.
- 📱 **Полноэкранный режим:** Клик по коду разворачивает его на весь экран для удобного считывания сканерами на кассах.
- 🎨 **Кастомизация и темы:** Светлая, тёмная, голубая и зелёная темы оформления, а также настройка индивидуального цвета для каждой карточки.
- 🔄 **Сортировка (Drag-and-Drop):** Изменение порядка карт перетаскиванием на ПК и смартфонах.
- 💾 **Автосохранение:** Все данные хранятся локально в `localStorage` браузера без необходимости регистрации.

## 🛠️ Используемые технологии

Проект написан на чистом **HTML5, CSS3 и JavaScript (Vanilla JS)** без сборки и фреймворков. Библиотеки подключаются через CDN:

- [JsBarcode](https://github.com/lindell/JsBarcode) — генерация линейных штрих-кодов (EAN-13, EAN-8, Code128, UPC).
- [QRCode.js](https://github.com/soldair/node-qrcode) — генерация QR-кодов.
- [QuaggaJS](https://serratus.github.io/quaggaJS/) и [jsQR](https://github.com/cozmo/jsQR) — распознавание кодов с загруженных изображений.

## 🚀 Запуск

1. Скачайте репозиторий или откройте файл `index.html` в любом браузере.
2. Для публикации на **GitHub Pages** выберите ветку `main` (папка `/root`) в настройках репозитория (**Settings → Pages**).

## 💡 Как пользоваться

1. **Добавить карту:** Нажмите **«📷 Сканировать с фото»** и выберите скриншот карты, либо введите цифры вручную и нажмите **«➕ Добавить»**.
2. **Показать на кассе:** Нажмите на сам штрих-код или QR-код, чтобы открыть его во весь экран.
3. **Редактировать:** Кликните по названию карты для переименования, по бейджу магазина для смены сети или по шестерёнке на карточке для выбора цвета.
4. **Удалить:** Нажмите на крестик в боковой панели карточки.
